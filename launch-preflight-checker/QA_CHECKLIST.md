# Финальный QA checklist

## Mini App

- [ ] Mini App открывается из Telegram без ошибки.
- [ ] Hero отображается корректно на мобильном.
- [ ] Popup / дополнительное описание hero открывается.
- [ ] Таймер присутствует; прошедшая исходная дата зафиксирована как проблема ТЗ.
- [ ] Верхний CTA регистрации работает.
- [ ] CTA после блока тем работает.
- [ ] В форме есть Имя, Телефон, Email.
- [ ] Форма успешно отправляется.
- [ ] После регистрации пользователь не попадает в дожимы.
- [ ] 4 темы раскрываются и содержат тексты из ТЗ.
- [ ] Спикерский блок отображается без пустых карточек.
- [ ] FAQ раскрывается.
- [ ] Нет тестового текста, пустых блоков и дублей hero.

## Дожимы

- [ ] Дожим 1 активен, задержка 5 минут.
- [ ] Дожим 2 активен, задержка 10 минут.
- [ ] Оба используют условие «форма не заполнена».
- [ ] CTA в обоих сообщениях возвращает в Mini App.
- [ ] В ссылках есть `utm_medium=dojim`.
- [ ] После заполнения формы сообщения не продолжают отправляться.
